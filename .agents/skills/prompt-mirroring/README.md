# Prompt Mirroring Skill

사용자가 설명한 기능이나 작업을 구조화해 되비추고, 모호함·모순·누락을 중요한 순서대로 확인한 뒤 합의된 Skill을 만드는 Codex 스킬입니다.

## 목적

Skill을 성급하게 작성하지 않고 다음 흐름으로 요구사항을 확정합니다.

1. 사용자의 설명을 구조화해 미러링합니다.
2. 중요한 미결정 사항을 한 번에 하나씩 질문합니다.
3. 모든 핵심 사항이 결정되면 최종 요구사항을 보여줍니다.
4. 사용자가 명시적으로 확인한 뒤에만 Skill을 생성합니다.

## 동작 방식

중요한 미결정 사항이 남아 있으면 `내가 이해한 내용`이라는 제목으로 현재 이해를 보여주고 질문 하나만 합니다. 이 단계에서는 `최종 요구사항`이라는 제목을 사용하지 않습니다.

중요한 질문이 모두 해결되면 `최종 요구사항`을 보여주고 사용자에게 확인을 요청합니다. 사용자가 “좋아”, “확정”, “이대로 만들어줘”처럼 명시적으로 승인하면 플랫폼 비종속 Skill을 생성합니다.

## 파일 구조

```text
prompt-mirroring/

```

## 사용 예

```text
$prompt-mirroring 방문 CS 처리 폼의 소요시간 입력 방식을 변경하려고 해...
```

## 관리 원칙

- 사용자가 말하지 않은 요구사항을 사실처럼 추가하지 않습니다.
- 확정된 내용, 추론, 기본 가정, 미결정 사항을 구분합니다.
- 질문은 결과에 가장 큰 영향을 주는 것부터 한 번에 하나씩 합니다.
- 사소한 내용은 합리적인 기본값으로 처리해 대화를 불필요하게 늘리지 않습니다.
- 사용자가 요청하지 않으면 특정 플랫폼 문법에 종속된 Skill을 만들지 않습니다.

## 검증

스킬을 수정한 뒤 다음 명령으로 기본 형식을 검증합니다.

```bash
python3 /Users/yusunsang/.codex/skills/.system/skill-creator/scripts/quick_validate.py /Users/yusunsang/.codex/skills/prompt-mirroring
```

정상이면 `Skill is valid!`가 출력됩니다.
