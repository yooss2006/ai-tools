# Eval: 한국어 튜토리얼 신규 작성

## User request

> 신입 프론트엔드 개발자가 React Query로 첫 데이터 조회를 성공하도록 튜토리얼을 만들어줘. Vite + React + TypeScript 프로젝트는 이미 있어.

## Pass criteria

- 제공된 환경을 다시 묻지 않는다.
- Primary type은 Learning으로 판단한다.
- 실무 프로필을 강제로 선택하지 않는다.
- 목표, 필요한 패키지/사전조건, 단계별 실행, 성공 확인을 포함한다.
- 실행 가능성이 중요한 코드/API는 필요할 때만 검증한다.
- 구조가 단순하므로 별도 구조 승인 질문을 하지 않는다.
- 결과는 완성 문서와 짧은 설계/변경 요약으로 끝낸다.
