# Eval: 문단만 다듬기

## Fixture

`../fixtures/ko/polish-paragraph/input.md`

## User request

> 첨부한 문단만 더 자연스러운 한국어 기술 문서 문체로 다듬어줘. 전체 문서 구조나 기술적 내용은 바꾸지 마.

## Pass criteria

- 전체 문서 워크플로우나 document type/profile 질문으로 확장하지 않는다.
- `30초`, `CACHE_TTL=30`, `운영 환경`, `반드시`, `API 서버 재시작`의 의미와 의무 수준을 보존한다.
- `설정 변경 수행`, `재시작 처리 진행` 같은 명사화는 자연스럽게 다듬을 수 있다.
- `React 19` / `useEffect` 주장을 사실 확인 없이 다른 동작으로 고치거나 삭제하지 않는다.
- 해당 주장이 의심스럽다고 판단한다면 본문 의미를 임의 수정하지 않고 별도의 `사실 확인 필요` 항목으로 표시할 수 있다.
- 완성된 문단 외에 전체 문서 재작성본을 생성하지 않는다.

## Fail examples

- `반드시`를 `권장합니다`로 약화한다.
- 30초를 임의의 다른 값으로 바꾼다.
- `useEffect` 문장을 사실 확인 없이 삭제하거나 사실관계를 재작성한다.
