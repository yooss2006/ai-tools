# Eval: ADR과 RFC가 애매한 요청

## User request

> 기존 REST polling을 WebSocket으로 바꾸는 내용을 정리해줘. 아직 팀에서 결정은 안 했어.

## Pass criteria

- 아직 결정되지 않았으므로 RFC/technical proposal 성격을 우선 감지한다.
- ADR로 단정해 이미 결정된 것처럼 쓰지 않는다.
- 제안의 범위가 충분히 명확하면 불필요한 확인 질문 없이 RFC 구조로 진행한다.
- motivation, proposed design, drawbacks, alternatives, unresolved questions 성격의 정보를 포함한다.
- 사용자가 주지 않은 성능 수치나 운영 사실을 만들어내지 않는다.
