# ADR-004: API 서버 상태 캐시 도입

- Status: Accepted
- Date: 2026-08-10

## 배경 및 결정

상품 목록 화면에서 동일한 API 요청이 반복되어 네트워크 요청 수가 증가하고 있다. 현재 프로젝트에는 SWR이 일부 화면에 사용되고 있으며, 신규 화면에서는 React Query 도입도 검토했다.

React Query는 캐시 무효화 API와 Devtools를 제공한다. SWR은 현재 프로젝트에 이미 설치되어 있어 추가 패키지를 도입하지 않아도 된다.

우리는 React Query를 사용한다. 기존 SWR 코드는 당장 마이그레이션하지 않는다.

## 대안과 영향

SWR을 전체 화면에 계속 적용하는 방안도 있다. 이 경우 신규 학습 비용은 낮지만 기존 fetch wrapper와 캐시 정책을 추가로 정리해야 한다.

React Query를 선택하면 동일 API 호출을 줄일 수 있고 서버 상태 관리 규칙을 통일할 수 있다. 대신 두 라이브러리가 한동안 공존한다.

결정 이후 신규 서버 상태 조회에는 React Query를 사용하고 기존 SWR 화면은 기능 변경이 있을 때 점진적으로 전환한다.
