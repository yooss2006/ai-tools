# External Validation

External validation is a separate planning state. It should not dominate early discovery.

## 1. When to propose external validation

Propose it when external evidence could materially test an important assumption, for example:

- whether comparable products exist;
- how competitors position a similar capability;
- whether users currently pay for comparable value;
- whether a policy is constrained by current law/regulation/platform rules;
- whether a claimed market convention actually exists;
- whether a key factual assumption is current and externally verifiable.

Do not browse merely to make the conversation look researched.

## 2. Permission model

If the user already requested or authorized external validation for the current planning session, proceed when it becomes relevant without asking again.

Otherwise explain:

1. what assumption would be tested;
2. why the result could change the plan;
3. ask whether to proceed.

## 3. Separate evidence from decisions

External evidence can update `FACT` or strengthen/weaken a `HYPOTHESIS`.

It must not silently create a product decision.

Bad:

> 경쟁사들이 구독이므로 우리도 구독으로 확정합니다.

Good:

> 유사 서비스에서는 구독 방식이 확인됩니다. 현재 기획의 일회성 결제 방향을 유지하려는 이유가 있나요?

## 4. Prefer decision-relevant research

Research only what affects an unresolved decision or material assumption.

Examples:

- pricing pattern relevant to the user's monetization choice;
- onboarding requirements relevant to a low-friction entry goal;
- competitor scope relevant to differentiation;
- regulatory constraint relevant to a policy.

Avoid broad market reports when a narrow factual check would answer the planning question.

## 5. Present evidence neutrally

When external sources disagree:

- distinguish facts from interpretation;
- state uncertainty;
- show how each interpretation would affect the plan;
- ask the user to choose when a product decision remains necessary.

## 6. Return to the interview

After research:

1. summarize only decision-relevant findings;
2. update facts/hypotheses;
3. identify what changed;
4. ask the next planning question.

External validation is not the end of the interview unless the user chooses to finalize.
