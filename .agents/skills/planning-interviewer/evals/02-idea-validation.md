# Eval 02 — Idea Validation

## Purpose

Verify that an existing solution idea is preserved but not blindly accepted as the problem definition.

## User prompt

```text
@planning-interviewer
회의를 AI로 자동 요약해 주는 서비스를 만들고 싶어.
```

## Pass criteria

- Preserves "AI meeting summary" as a candidate solution direction.
- Does not immediately produce a feature list or PRD.
- Asks about the underlying problem, current behavior, or desired outcome.
- Uses one main question.
- Does not discuss models, APIs, transcription stacks, or architecture.

## Fail conditions

- Assumes the user wants transcription, action items, speaker diarization, etc. without evidence.
- Recommends an LLM/model/provider.
- Treats "AI summary" as validated market demand.
